* Summary

I wrote 48 =.fspy= documents (=eval/literature/=): dialectical proofs of
propositional theorems and the standard examples from abstract
argumentation, ADFs, structured argumentation (ASPIC+-style examples),
ABA, Carneades, s(CASP) and Catala. I ran each through a harness
(=eval/harness.py=) that labels every argument under grounded, preferred
and stable semantics, evaluates it skeptically and credulously, and
checks *adequacy*: a credulous value exactly when some labelling has the
issue IN, a skeptical value exactly when every labelling has. I compared
the labels with independent brute-force solvers for Dung frameworks and
ADFs and with s(CASP) 0.25 itself, and I swept the same checks over the
repository's 60 fixture scripts.

The headline results:

- *Labelling of the document graph is sound against Dung and ADF
  semantics.* 161/161 abstract frameworks (11 from the literature, 150
  random) agree with Dung on grounded, complete, preferred and stable.
  155/161 ADFs agree with the ADF semantics of Brewka et al. (2013); the
  six that do not all have a condition containing "b or not b", which
  AIDA cannot see as a tautology because b and its refutation are two
  statements.
- *Adequacy held in 912 of 912 evaluations* of encoded abstract
  frameworks, and in all literature examples except the bugs below.
- *Dialectical proofs work.* Transitivity, contraposition and Peirce's law
  evaluate to their proof terms with the type check on; double negation
  elimination and consequentia mirabilis evaluate to the correct classical
  proof terms only with the type check off (bug 4); proof by cases hits
  bug 2.
- *Eight bugs and five specification questions*, listed in [[*Bugs][Bugs]] and
  [[*Specification questions][Specification questions]], each with a minimal reproduction.
  The most serious: an exposed lemma is lifted out of the lambda that
  binds its hypothesis, so evaluation returns a "value" with a free
  variable while the issue is labelled OUT (bug 2); and credulous
  evaluation under grounded semantics can be OPEN where skeptical is a
  value (bug 3).
- *Part 2* (sequent-based argumentation, adaptive logic, defeasible and
  defeasible deontic logic, default justification logic,
  circumscription, the event calculus, I/O and reified I/O logic; 26
  more documents): no new bug class, but two new consistency failures on
  [[id:aida-strict-layer]], a second reproduction of bug 2, and a map of
  the first-order gaps.
- *Part 3* (re-run after the fixes): bugs 1-8 verified fixed; the
  cross-checks unchanged; two new bugs (9: a scaffold on an elimination
  cell gets no label; 10: the subarguments setting changes labels and
  verdicts, contrary to the README).
- *Part 4* (first order, after first-order debates were added; 16
  documents): event calculus, reified I/O logic, inductive
  generalisation and the abnormality reading of rule schemas give the
  literature's verdicts on both routes; a counter-instance refutes a
  universal rule for everyone (by design); classical first-order
  theorems that throw an open statement cannot be argued; two new bugs
  (11: an exposed horn with an open source labels a strict theorem OUT;
  12: keyword names give a bare parse error).
- *Part 5* (problem cases from the literature; 19 documents): Lifschitz's
  default-reasoning and inheritance benchmarks, Touretzky, drowning,
  Chisholm and the legal priority example come out as expected, with
  specificity and priorities written as abnormality and undercuts; the
  stolen car and the murder mystery fail for want of backward reasoning;
  Prakken's closure counterexample is reproduced with derived premises;
  one statement cannot be presumed by one argument and owed by another
  (new design task).

* Results by source

** Dialectical proofs of propositional theorems

Each proof is a sequence of one-inference moves: the proponent claims the
thesis, the skeptic introduces the hypotheses and demands the conclusion,
each further move owes what it uses. Unfolding composes the moves by
capture (a demand met by a binder already in scope).

| file                   | theorem                              | type check on                | type check off            |
|------------------------+--------------------------------------+------------------------------+---------------------------|
| t_transitivity         | (A->B)->(B->C)->A->C                 | VALUE, the proof term        | same                      |
| t_contraposition       | (A->B)->(~B->~A)                     | VALUE, the proof term        | same                      |
| t_peirce               | ((P->Q)->P)->P                       | VALUE, classical proof       | same                      |
| t_dne                  | ~~A->A                               | refused by the type check    | VALUE, classical proof    |
| t_mirabilis            | (~A->A)->A                           | refused by the type check    | VALUE, classical proof    |
| t_cases                | (A->B)->((~A->B)->B)                 | refused (free variable h)    | VALUE with free h, label OUT (bug 2) |
| t_subtraction          | refute A-A; refute B-B dialectically | VALUE                        | same                      |
| t_lnc, t_lnc_dialectical | ~(P-P), outright and dialectically | VALUE                        | same                      |
| t_nontheorem           | (A->B)->(B->A)                       | OPEN, issue OUT              | same                      |
| t_nontheorem_presumed  | same, A presumed and counter-presumed| credulous VALUE, skeptical OPEN | same                   |
| t_refute_invalid       | refute A->B by a countermodel        | refutation VALUE, claim EXCEPTION | same                 |

Two restrictions of the term language shaped these proofs: =~~A= had to
be written =(A->false)->false= and falsum left as an obligation met by a
separate refutation of =false= (bug 1), and excluded middle has no
statement of its own, since disjunction is not in AIDA's fragment.

** Abstract argumentation (Dung)

- *Document graph:* the 11 literature frameworks (unattacked, self-attack,
  reinstatement chain, mutual attack, odd 3-cycle, even 4-cycle, floating
  reinstatement, a self-attacker attacking another, an odd cycle attacking
  out, Dung's 1995 example, a framework with a preferred but no stable
  extension) and 150 random ones (up to 5 arguments) agree with Dung on
  all four semantics: 161/161 (=results/af_literature.txt=,
  =results/af_random.txt=).
- *Issue graphs:* over 60 random frameworks (=results/af_eval.txt=),
  912 evaluations, 0 adequacy mismatches; 116 issue labels differ from
  Dung, every one of them explained by two causes: a self-attacking
  argument reachable from the issue (69 under grounded and preferred, 32
  under stable), which the issue graph labels OUT where Dung says UNDEC
  (specification question 2), and stable semantics not being local (15:
  a self-attacker elsewhere leaves Dung without a stable extension, while
  the issue graph does not see it). =af_selfattacker_target.fspy=: for
  =a -> a, a -> b= Dung and the document say a, b UNDEC and no stable
  extension; =evaluate b= gives a VALUE, b IN.

** Abstract dialectical frameworks

=results/adf_literature.txt=: support chain, attack chain, joint attack,
joint support, mixed conditions, a non-bipolar condition (exclusive or),
self-support, a support cycle, a support cycle with a founded base, odd
and even negative loops: 11/11 agree with the reference on all four
semantics. =results/adf_rand.txt=: 155/161 with the random ones. The six
disagreements all contain a tautologous condition (=a: a | ~a=,
=a: ~b | b&c= with c true, ...): the reference evaluates "b or not b" as
true when b is undecided; AIDA's ADF is over statements, b and its
refutation are separate statements, and the disjunction of two undecided
statements is undecided. Under stable semantics =a: a | ~a= has the
model {a} in the ADF semantics and none in AIDA (which here agrees with
answer set programming).

So AIDA expresses every ADF condition up to this point: bipolar or not,
joint attacks and supports, through presumed refutations as negative
literals.

| file           | framework                                  | AIDA                                               | ABA                                    |
|----------------+--------------------------------------------+----------------------------------------------------+----------------------------------------|
| aba_toni       | Toni's tutorial example                    | a OUT, p OUT, r IN, b, c IN                        | same (grounded)                        |

** Carneades

| file                 | situation                                        | AIDA                                       | Carneades                                         |
|----------------------+--------------------------------------------------+--------------------------------------------+---------------------------------------------------|
| carneades_contract   | pro (agreement, consideration, no minor) vs con (statute of frauds) | credulous VALUE, skeptical OPEN | scintilla: acceptable; dialectical validity: not; preponderance: by weights |
| carneades_exception  | exception (minor) proved                         | Contract OUT                               | not acceptable                                    |
| carneades_questioned | assumption questioned                            | onus-conflict warning, Contract UNDEC; credulous VALUE | not acceptable until proved              |

Premise types map directly: an ordinary premise is an obligation, an
assumption a presumption, an exception the presumed refutation of the
exception. Proof standards map only at the two ends (scintilla of
evidence to credulous, dialectical validity to skeptical); weights and
audiences cannot be written. Questioning has no counterpart: the closest
is a counter-presumption, which AIDA reports as an onus conflict.

** s(CASP)

Rules are declared implications, an atom premise an obligation, =not b=
the presumed refutation of b, a constraint =:- p= a denied P
(=moxia=). Grounded by hand to propositional atoms.

| program              | query               | s(CASP) 0.25           | AIDA (issue)                                   |
|----------------------+---------------------+------------------------+------------------------------------------------|
| birds (=scasp_birds=) | flies(tweety)      | {flies(tweety), not ab(tweety)} | IN, VALUE                             |
|                      | flies(sam)          | no models              | OUT, OPEN                                      |
| even loop            | p                   | {p, not q}             | credulous VALUE, skeptical OPEN                |
| odd loop + fact r    | p                   | no models              | IN under every semantics, VALUE                |
|                      | r                   | no models (global check) | IN, VALUE                                    |
| positive loop        | a                   | no models              | grounded UNDEC; one preferred labelling IN (credulous VALUE =!IN:A=); stable OUT |
| loop with founded base | b, a              | {b, a}, {a}            | IN, VALUE                                      |
| even loop + =:- p=   | q / p               | {q, not p} / no models | IN, VALUE / OUT, EXCEPTION                     |

Agreement on the normal cases. Differences: the odd loop =p :- not p= is
read classically, as =(~P->P)->P=, so P is proved (the author's decision
for self-attack; at the document level P is UNDEC and there is no stable
labelling, as in s(CASP)); and AIDA answers locally, so the fact r
stands beside an inconsistent part, where s(CASP)'s global check fails
every query. The positive loop agrees under stable semantics only; under
preferred an unfounded loop is accepted credulously, as documented.

** Catala

| file             | situation                               | AIDA                                        | Catala                    |
|------------------+-----------------------------------------+---------------------------------------------+---------------------------|
| catala_exception | base rate, applicable exception         | Rate15 IN, Rate20 OUT                       | 15%                       |
| catala_nested    | exception to an exception               | Eligible OUT, refutation VALUE              | false                     |
| catala_empty     | no base, exception not applicable       | Rate15 OUT, OPEN                            | NoValueProvided error     |
| catala_conflict  | two applicable exceptions               | EXCEPTION for both                          | ConflictError             |

A base definition is a bare presumption, an exception a derivation from
its condition, a variable's single value a strict exclusion between the
propositions for its values. Catala's two run-time errors have
counterparts: an empty default is OPEN, a conflict an EXCEPTION. Values
other than truth values (amounts, dates) and arithmetic cannot be
written. =catala_conflict= also shows specification question 1.

** Grounded predicate logic and first-order rules

Ground atoms in predicate syntax (=Bird [tweety]=) work throughout:
=grounded_predicate.fspy= labels and evaluates like its propositional
twin. A quantified defeasible rule (=first_order.fspy=, =forall x, Bird
[x] -> Flies [x]= presumed and instantiated at tweety) is refused, as the
README says, but with the wrong message (bug 8).

** Debates

=debates_tweety.fspy= exercises open and closed debates, both onus sides
and the verbs. Every move is checked as documented: =attack= and =rebut=
on the conclusion pass, =undermine= reaches the presumed rule, =support=
of a refutation and =undermine= of a non-presumption are refused with
clear messages; a closed debate hears only its moves (the rebuttal alone
leaves the contest open, adding the undercutter decides it).

** Refinement, citation, adoption

=refinement_citation.fspy=: a lemma is an obligation until refined; a
citer follows the refinement (late binding: B goes from OUT to IN); =qed=
refuses while a presumption remains, with a clear message.

* Expressivity: what can and cannot be written

Can be written today:
- abstract frameworks (exactly, at the document level);
- ADFs whose conditions are in disjunctive normal form, bipolar or not
  (exactly up to tautologous conditions);
- rebuttals, undercuts (refuting a presumed rule), undermining
  (refuting a presumed premise), and attacks on the conclusion of a
  strict rule by a strict refutation;
- burden of proof: obligations against presumptions, which gives
  Carneades' premise types and Catala's base-and-exception structure;
- normal logic programs with negation as failure and constraints,
  grounded to atoms;
- ground predicate atoms;
- dialectical proofs in the implicational fragment with negation and
  subtraction, classical ones included.

Cannot be written today:
- preferences, priorities, specificity, weights, proof standards beyond
  the credulous/skeptical pair, audiences;
- conjunction and disjunction (and a document that uses them crashes,
  bug 6), hence no excluded middle as a statement;
- quantified rules in debates (refused);
- data values and arithmetic (Catala's amounts, s(CASP)'s constraints
  over numbers);
- contraposition of rules and the bridge between =~K= proved and K
  refuted (=aida-strict-layer=), so the consistency postulates fail on
  the married-bachelor example;
- Carneades' "questioning" of an assumption as a speech act.

* Bugs

Each is judged against AIDA's own documentation. Files are in
=eval/literature/=, outputs in =eval/results/=.

1. *An argument that applies a negation to an open site is silently left
   out of the document graph.* =bug_falsum_cell.fspy=: =cut (~A) g. next.
   elim. next.= (A owed) leaves the cell =?:A * _F_=; the compiler finds
   no proposition on it ("Edge 'x1.c1': root proposition missing; run
   enrichment first") and drops the argument, also when =~A= is a
   declared axiom. A user sees only a warning at registration, and
   =Service.check= reports the =dixi= as =ok= (the warning is in the
   report-level diagnostics only). The same happens with
   =(A->false)->false= once the falsum context is closed by =elim=. This
   is what blocked the direct dialectical proof of double negation
   elimination. Where: =_root_statement= in =core/dc/debate_graph.py=,
   reached for a =Cons= horn whose tail is =_F_=.

2. *An exposed lemma is lifted out of the lambda that binds its
   hypothesis.* =t_cases.fspy=, =p3=: =λh:A. ... μy:B.<f || h*y> ...=.
   The lemma =p3.μ1= (B from A->B and A) is compiled with A as an
   obligation and then placed in B's stack at the top of the debate,
   outside =λh=, so =h= is free. With the type check on, every query is
   refused ("h is neither in your hypothesis nor in your conclusion");
   with it off, both modes return =VALUE=
   =μs1:...<λf.λg.μalt5:B.<f || h:A*alt5:B> || s1>= although the issue
   is labelled OUT, because the strict phase counts the lifted lemma as
   strict. This breaks the stated invariant that the unfolded term is
   closed (tasks.org, the strict-phase decision of 2026-09-25) and
   adequacy. Recent: exposure of lemmas is from 2026-10-15/16.

3. *Credulous evaluation under grounded semantics can be OPEN where
   skeptical is a value.* =bug_credulous_tiebreak2.fspy= (no warnings
   involved) and the repository's own =tests/olon.fspy= (=first=,
   =tester=, =final= ...): A is presumed and IN in the single grounded
   labelling; a further supporter of A rests on a presumption of an UNDEC
   statement B. Skeptical: =VALUE !IN:A=. Credulous: the trace says
   "supporter A[t] is UNDEC -> keep the supporter (credulous tiebreak),
   dropping the original", B's presumption, labelled UNDEC, becomes an
   obligation, and the verdict is =OPEN=. =core/comp/evaluate.py= says
   the choice of witness "only affects the normal form ..., never the
   verdict", and the 2026-09-16 record says grounded makes credulous
   coincide with skeptical. A second symptom
   (=bug_credulous_tiebreak_value.fspy=): with B contested by two
   derivations, credulous grounded evaluation returns a value whose term
   keeps the derivation of B and drops its attacker, although grounded
   does not accept B.

4. *The type check refuses dialectical proofs whose evaluation is
   correct.* =t_dne.fspy= and =t_mirabilis.fspy=: per sub-debate,
   "Fellowship reconstructed a different term for 'p1_1' than the one
   unfolded; the instructions do not encode the term. The shapes first
   differ at mu/3/mutilde/3/mutilde/2"; with =typecheck expanded=, "This
   is not trivial. Work some more." With the check off both evaluate to
   the textbook classical proofs (=results/t_dne_typecheck_off.txt=). The
   sub-debate in question is the one about =A->false=, in which the
   refutation of A owed by =λh:A.μk:false.<h || ?>= is captured by an
   enclosing continuation. Peirce's law, with the same kind of capture,
   passes; so the replay's instruction generator, not the term, looks at
   fault.

5. *A binder named =_= poisons every debate that reaches its statement.*
   =bug_underscore_binder.fspy=: =cut (P) _.= is accepted by Fellowship
   and registered; every query about P, of every argument, is then
   refused by the type check ("_ is neither in your hypothesis nor in
   your conclusion"), and with the check off evaluation fails ("free
   context variable '_' is neither bound nor a declared axiom"). The
   unfolder uses =_= for its own unused binders. The repository's
   =tests/thetaexpander_bureaucratic_cases.fspy= (=affine_parent=) makes
   all nine of its arguments unqueryable this way.

6. *A conjunction in an argument crashes the CLI and =Service.check=.*
   =expressivity_connectives.fspy=: =dixi= on an argument whose
   conclusion or a cut mentions =/\= raises =SyntaxErrorInSource=
   ("cannot parse 'A /\ B' as a prop"): the CLI exits 1 with a traceback
   and =Service.check= raises instead of reporting the entry and going
   on. The README says such propositions can be declared but not argued
   about; the expected behaviour is a one-line refusal.

7. *An argument for a negation can lose its name and provenance.*
   =bug_negation_edge_name.fspy=: =argument negA : (~A). elim h. next.
   dixi.= gives the edge =H1 (argument, defeasible): ~A[t] <- A[c:obli]=;

   cannot link the edge to negA's block. =H1= is Fellowship's wrapper

8. *The first-order refusal has the wrong message and the argument

* Specification questions

These follow from documented decisions but give results the author may
want to look at.

1. *Labels depend on the issue asked even in a purely strict document.*
   =catala_conflict.fspy= has facts and declared rules only. The
   statement "Rate15 refuted" is IN in the issue graph of =exc1=, OUT in
   that of =exc2= and in the document graph. The cause: an argument with
   an obligation is a defeasible edge even when a strict argument meets
   the obligation, and the strict phase adds a strict edge only for the
   closed derivations of the issue's own term. The README allows issue
   graphs to differ; here two queries contradict each other about one
   statement. The strict contradiction (both sides of Rate15 strictly
   derivable) is visible only at DEBUG.
2. *Self-attack is read classically per issue, not per document.* For a
   self-attacking argument the document graph agrees with Dung, ABA and
   s(CASP) (UNDEC, no stable labelling); an issue graph that reaches it
   labels it OUT, and its targets IN (=af_selfattacker_target.fspy=,
   =aba_selfattack.fspy=, =scasp_odd.fspy=). This is the decided
   classical reading (=(A->~A)->~A=), but it means that =label document=
   and =label ARG= answer differently, and that a framework without a
   stable labelling has issues with one.
3. *A floating conclusion evaluates skeptically to a bare delegation.*
   =nixon_floating.fspy=: Political is IN in both preferred labellings and
   skeptical evaluation gives =VALUE !IN:Political=: the root obligation
   is discharged as a delegation by its label, and the value holds no
   argument. A classical case split on Dove would be a proof term for
   it. The six ADF disagreements are the same phenomenon under grounded.
4. *A strict contradiction labels both sides IN.* =rationality_crash.fspy=,
   =catala_conflict.fspy=, =tests/default_test.fspy=: both sides IN and
   evaluation EXCEPTION, so "IN implies a value" does not hold there.
   Defensible (Catala raises an error in the same place), but adequacy as
   stated in the minicourses does not mention it, and nothing above DEBUG
   says the document is inconsistent.
5. *The credulous fallback can name a label the chosen semantics does not
   give.* =scasp_positive.fspy=: under stable the issue is OUT, and
   credulous stable evaluation prints =?UNDEC:A=, the grounded label of
   the documented fallback. Documented; it may confuse a reader of the
   normal form.

** Sequent-based argumentation

Arieli & Straßer (2015) and Arieli, Borg & Straßer (2018) relate the
stable and preferred extensions of sequent-based frameworks over
classical logic (with, among others, the Undercut rule) to the maximal
consistent subsets (MCS) of the premises. For S = {p, q, p -> ~q} the
MCS are {p, q}, {p, p->~q} and {q, p->~q}.

- =seq_mcs.fspy= writes only the attack that applies the rule forwards
  ({p, p->~q} => ~q). AIDA: p and the rule IN, q contested (two
  preferred). The attacks a classical base logic adds, on p by modus
  tollens and on the rule, are absent: AIDA builds no attack it was
  not given (no closure under the base logic).
- =seq_mcs_closed.fspy= writes all three attacks. Preferred and stable
  give *four* labellings: the three MCS and one in which p, q and
  p->~q are all IN and every attack OUT. Each attack owes its
  premises, so its edge is defeasible, and the premise it attacks
  rebuts it. The accepted set is classically inconsistent: indirect
  consistency fails even with every contraposition written by hand.
  Recorded under [[id:aida-strict-layer]].
- Writing the modus tollens attacks with =~Q= drops them from the graph
  (bug 1); the file spells the rule =P -> Q -> false=.

** Adaptive logic

- =adapt_ds.fspy=, Γ = {p, ~p v q, r, ~r, ~r v s}: both adaptive
  strategies finally derive q, not s. AIDA: q IN; r and s contested (s
  credulously only). Agreement, reading a disjunction with a negated
  disjunct as the rule it licenses.
- =adapt_minab.fspy=, Γ = {~p, ~q, p v q, p v r, q v s}: reliability
  derives none of r, s, r v s; minimal abnormality derives r v s only.
  AIDA (type check off; the file mixes =~P= and =P->false=, the known
  two-spellings refusal): r and s are IN even under grounded. The derived
  =~P[t]= (from the source of ~p) is never contested by the derivation
  of P[t] (from ~q and p v q), so r stands. The missing negation bridge,
  [[id:aida-strict-layer]]. With the bridge, r and s would be contested,
  which matches reliability; minimal abnormality's disjunction r v s has
  no statement in AIDA (no disjunction; =~r -> s= would need a case
  split).
- Inductive generalisation (Batens' IL, first order):
  =adapt_induction_fo.fspy= presumes =forall x, Pr x= and instantiates it
  with =elim [c]=: refused (bug 8's message). =fo_opaque.fspy= keeps the
  universal statement opaque and supplies instantiation and the
  counter-instance as declared schema instances; then the
  generalisation is refuted by the counter-instance at d and the
  instance at c is not derived, as in IL.

** Defeasible deontic logic

** Default justification logic

Pischke (2017, 2018) builds Reiter-style defaults over justification
logic: reasons are terms (t : F), and an undercutter attacks a reason,
not its conclusion. AIDA's arguments are proof terms too, but a term is
not a statement, so no proposition says "t is a reason for F", and the
debate verbs reach statements, not arguments.
- =djl_reasons.fspy=: two witnesses share one presumption of
  reliability; undercutting the first witness refutes the shared
  statement and Robbery goes OUT with both arguments.
- =djl_reasons_own.fspy=: one presumption per witness; the undercutter
  hits only the first, Robbery stays IN through the second, as in
  justification logic. The modeller must anticipate which reasons may be
  attacked separately.
- Not expressible: justifications of justifications (t : (s : F)),
  operations on reasons inside formulas, the proof checker !.

** Circumscription

- =circ_disjunctive.fspy=: two birds, one of them abnormal. The minimal
  models of circumscribing ab are {ab1}, {ab2}; AIDA's preferred and
  stable labellings are exactly these two (flies1 in one, flies2 in the
  other), grounded leaves all UNDEC. Circumscription also concludes
  flies1 v flies2, which has no statement in AIDA; it is the floating
  conclusion of question 3 again.
- =circ_fo.fspy=: predicate circumscription minimises the extension of
  Ab over the domain and concludes universal statements (here, nothing
  is abnormal). The presumed =forall x, ~Ab x= is accepted as an opaque
  statement; applying the quantified rule to tweety is refused. Grounding
  needs a finite, named domain and unique names, which circumscription
  does not assume.

** Input/output logic

- =io_out1_out3.fspy= and =io_out3.fspy=, G = {(a,b), (b,c)}, A = {a}:
  out1 outputs b only, out3 also c. A norm (a,x) is a rule from input a
  to an output atom; with the rule for (b,c) reading its input from
  Ob only in io_out3, AIDA reproduces out1 and out3 respectively. The
  output operation is fixed by which rules the modeller writes; AIDA
  has no closure Cn on inputs or outputs.

  refutation.

** Reified input/output logic

Robaldo & Sun (2017) combine I/O logic with Hobbs' reification: norms
quantify over eventualities, and Rexist(e) says that e really happens,
so an obligation can be about an eventuality that does not exist.
- =rio_gdpr.fspy= / =rio_gdpr_complied.fspy=: a ground instance
  (processing e1 obliges informing; "no inform eventuality exists" is
  presumed over the named candidate e2): violation IN without the
  information, OUT with it. Agreement for the ground case.
- =rio_fo.fspy=: the norm as written is universally quantified with an
  existential obligation, =exists e, Inform e ctrl subj=. The
  existential statement can be presumed and evaluates as an opaque
  statement (VALUE =!IN:exists e:Ev, ...=); deriving it from a
  witness eventuality, or instantiating the universal norm, is refused.
  Reification's other features - eventualities of obligations, Rexist
  over nested eventualities - need the same first-order machinery.

** Findings

- *Specificity, inheritance, priorities* (A3, B1, Touretzky, legal
  priorities): AIDA has no preference relation, but every case comes out
  as expected once specificity is written as abnormality or undercut and
  a priority principle as an undercut of the losing rule; meta-priorities
  are undercuts of undercuts. The redundant link does no harm: the
  direct and the path argument both rest on the same presumption of
  normality, which the royal exception defeats. No drowning: an
  exception defeats one rule, not the class.
- *The onus belongs to a statement* (railroad): one argument presuming
  the refutation of Train makes it presumed for another that owes it, so
  negation as failure and classical negation of the same proposition
  cannot both be written in one document. New design task
  [[id:aida-onus-per-statement]].
- *Prakken's closure counterexample reproduced* (prakken_bm_sources):
  with fallible premises derived from sources, a preferred labelling
  accepts b and m against the strict b -> ~m. With bare presumptions it
  does not: a presumption keeps its guard, a derivation of its contrary
  wins. The lottery shows the same (an "all tickets lose" labelling).
  Note on [[id:aida-strict-layer]].
- *The lottery*: no reading of either Pollock or Prakken is reproduced
  skeptically; grounded is undecided throughout, credulous accepts any
  single winner (and, with sources, also "all lose").
- *No reasoning backwards* (stolen car, murder mystery): forward
  persistence concludes the car was still there at 1 and 2 -
  chronological minimisation's answer, which the literature rejects -
  and the loaded gun is not inferred from the death. Transposition (not
  implemented) would contest the first; the second also needs the
  clipping rule read as the only cause (completion), which AIDA has no
  means to state.
- *Self-defeat* (Pollock): the issue graph proves Smith unreliable by
  the classical reading of self-attack, where Pollock keeps him
  reliable and the document is undecided; note on
  [[id:aida-self-attack-document-vs-issue]].
- *Open domains* (A4): a universal conclusion with an exception needs
  equality or a per-individual universal; with a universal normality
  presumption the exception refutes it; note on
  [[id:aida-first-order-reduction]].
- *Contrary-to-duty* (Chisholm): fine with obligations as atoms; no
  deontic inference (from O go and "going obliges telling" no O tell
  follows unless written), so the standard-deontic-logic paradox does
  not arise - nor do its intended inferences.
- *Not expressible*: Ross's paradox and free choice permission need
  disjunction; the Russian turkey shoot needs a nondeterministic action
  (disjunction); Lifschitz's A5-A8 (unknown exceptions, priorities
  between defaults of different reliability) need disjunction,
  existentials over exceptions with equality, or a preference relation.

** Later problem cases, listed for when AIDA is a logical framework

Asked 2026-10-21: most cases above are old because the old ones fit
AIDA's fragment. The newer problem-case literature targets features AIDA
does not have yet; the author expects them to become expressible once
AIDA is a logical framework through superdeduction, so they are listed
here as the next test set. References are as I know them, not
re-checked against the papers; Tweety ships implementations or examples
of most of them (part 6).

- *Preferences between arguments.* Last-link versus weakest-link, elitist
  versus democratic set comparison, and the examples showing which
  orderings keep the rationality postulates (Modgil and Prakken, "A
  general account of argumentation with preferences", AIJ 2013; the
  postulates: Caminada and Amgoud, AIJ 2007). Preferences in ABA: ABA+
  (Čyras and Toni, KR 2016) and its counterexamples to reverse defeat.
  Tweety: =ex2.aspic=, =ex3.aspic= (rule orders), DeLP's generalized
  specificity.
- *Gradual and ranking semantics.* The h-categorizer (Besnard and Hunter
  2001), the tuples of Cayrol and Lagasquie-Schiex (2005), Grossi and
  Modgil's graded acceptability (IJCAI 2015), Amgoud and Ben-Naim's
  ranking postulates, the counting and propagation semantics surveyed in
  Delobelle's thesis (2017), Thimm, Cerutti and Rienstra's probabilistic
  graded semantics (COMMA 2018). Tweety: the seven =arg.rankings=
  examples and =RankingPostulatesExample=, which checks the postulates.
- *Probabilistic and epistemic argumentation.* Constellations (Li, Oren
  and Norman 2011), the epistemic approach (Hunter and Thimm), lotteries
  over frameworks; epistemic AFs with constraints over labellings.
  Tweety: =arg.prob=, =arg.eaf=.
- *Values and audiences.* Bench-Capon's value-based frameworks (2003),
  where an attack succeeds relative to an audience's value order.
- *Dynamics and enforcement.* Enforcing an extension by adding arguments
  or attacks (Baumann and Brewka 2010), change in frameworks (Cayrol, de
  Saint-Cyr and Lagasquie-Schiex 2010), equivalence notions (strong,
  expansion, serialisation equivalence). Tweety: =EquivalenceExample=,
  =AFLearnerExample= and =LearningExample= (learning a framework from
  labellings).
- *Weights, votes, constraints, incompleteness.* Weighted frameworks
  (Dunne et al., AIJ 2011), social frameworks with votes (Leite and
  Martins 2011), constrained frameworks (Coste-Marquis et al. 2006),
  incomplete frameworks with uncertain arguments and attacks. Tweety:
  =arg.weighted=, =arg.social=, =arg.caf=, =IncompleteReasonerExample=.
- *Further semantics.* CF2, stage, qualified and semi-qualified, weak
  admissibility, undisputed (vacuous reduct), serialisable semantics
  (Bengel and Thimm, COMMA 2022), stratified labellings. Tweety: the
  corresponding =arg.dung= examples.
- *Explanations.* Sufficient and sequence explanations of acceptance.
  Tweety: =arg.explanations=.
- *Causal and counterfactual reasoning* from structural equations,
  abductively from observations, with interventions. Tweety: =causal=.

* Part 6: the TweetyProject examples

Run 2026-10-21 on branch =eval-hard= (fast-forwarded to main at
=682b3c1=): every example of the TweetyProject (v1.31, git clone of
2026-10-18) in the argumentation, logic and causal modules. Files in
=eval/tweety/=. Tweety itself is the reference: its jars came from Maven
Central, its 97 example programs were compiled and run (66 ran as is,

(=eval/tweety/java/TweetyRef.java=, =ref.sh=) queries Tweety's ASPIC+,
DeLP, ABA, Dung and default-logic reasoners on every translated theory.

memory (the first-order default theory), the reference is a brute-force
solver of mine (=aba.py=, =asp.py=, =../dung.py=, =../adf.py=) or the

Translations are generated, not written by hand, wherever the source is
a rule file: =tw2fspy.py= turns ASPIC+, DeLP, ABA and default-logic files

owed and met by capture; encoding in its docstring), =extract_afs.py=

solves the ASP programs, =hand.py= builds the rest (set attacks,
attacks on attacks, supports, claims, deductive knowledge bases).
=compare.py= puts AIDA beside the reference literal by literal, in two
views: the *issue view* (a literal is accepted when the issue of an
argument for it is IN in its own issue graph; this is what =evaluate=

** Structured argumentation

- *ASPIC+* (=compare.py aspic=): ex1 (with an undercutter and strict
  rules) and ex4 (married/bachelor) agree with Tweety on all 16 and 8
  literals under all four semantics; ex2 and ex3 differ on exactly the
  two literals the rule preference decides, and agree once the
  preference line is removed. The first-order ex5 agrees with ASPIC+ on
  its grounding.
- *ASPIC+, random theories* (=random_batch.py=, labels only, grounded,
  =ACDC_TIMEOUT=300=): Tweety's generator gives 50 theories of 35 atoms
  and about 80 rules; the issue graph of a single argument takes up to
  a minute, a whole theory 4 to 20 minutes and theory 02 more than 50,
  so only 00 and 01 were run (=random.out=). Theory 01 has a consistent
  strict part and differs from ASPIC+ on four literals, all accepted by
  AIDA and by neither side in ASPIC+: =!A25= is strictly accepted, so
  =!A25 => !A7= is a derivation of =!A7=, which defeats the bare premise
  =A7= outright under the asymmetric guard
  ([[id:aida-asymmetric-contrariness-guard]]), where ASPIC+ without
  preferences lets the two rebut each other; =A19=, =!A31= and =A0=
  follow by the same rule down the chain. Theory 00 has contradictory
  axioms (=-> A19= and =-> !A19=), outside ASPIC+'s assumptions; two of
  its labellings were refused. With the first encoding (a negative
  premise derived rather than bare) theory 01 differed on six literals.
- *DeLP* (=compare.py delp=): against DeLP's answers the differences are
  all decided by generalized specificity (Tweety flies or not, tina,
  nixon's gun, stocks, dtree); against ASPIC+ without preferences on the
  same ground theory the issue view is identical on birds, birds2,
  dtree, hobbes, nixon and stocks. On =counterarg= (h <- a, ~h <- c, a
  and c defeasible) ASPIC+ accepts both h and ~h (no transposition),
  DeLP rejects a and c (they disagree through the strict rules), AIDA
  leaves h undecided and accepts a and c.
- *ABA*: the two flat theories agree with Tweety and with =aba.py= under
  all semantics. Tweety refuses the four non-flat ones; against
  =aba.py= (Bondarenko et al.'s definitions) AIDA gives the reading one
  expects of the flat version, which non-flat ABA does not: in example3
  ABA has a preferred extension {c} that is not complete, in example4
  no complete extension at all, in example5 no grounded one. The
  stable-marriage example (first order, grounded) gives exactly
  Tweety's two stable matchings.
- *Default logic*: the simple theory's two extensions are AIDA's two
  preferred and stable labellings, d and ~d credulous, a, b, c
  skeptical. Tweety's reasoner runs out of heap on the first-order
  theory; its single extension (Tweety flies, the penguin does not) is
  AIDA's issue view.
- *ASP*: on ex1-ex6 (with classical negation, a constraint, a shifted
  disjunction and a choice rule) the stable labellings are the answer
  sets. AIDA's one negation stands for both =not x= and =-x=; the
  comparison has to be told which atoms the program negates
  classically.

** Other frameworks

- Set attacks (SETAF), Modgil's extended frameworks and the recursive
  ones: all exact, attacks on attacks written as undercutters of
  presumed attack rules, attacks on those as undercutters of
  undercutters.
- Bipolar: necessity support (c argued only from a) is exact. Deductive
  support as a strict rule a -> x is not: Tweety's preferred extension
  {a, x} drops b, because b supports c and x attacks c; AIDA keeps b IN,
  and both its labellings accept a strict rule with an IN premise whose
  conclusion is refuted.
- Claim-based: with an attack on the claim, as AIDA's attacks go, the
  extension with both claims is lost; with each argument a premise that
  yields its claim, AIDA's claim sets are Tweety's cl-preferred
  ({c1}, {c2}, {c1, c2}).
- Deductive argumentation: the Besnard-Hunter knowledge base leaves h
  undecided (one argument, two undercuts); the categorizer's value -2.0
  has no counterpart. The simple PL logic example is exact.
- Causal reasoning (abduction from structural equations), dialogue
  simulations (=agents.dialogues=, multi-agent protocols), conditional,
  description, modal, probabilistic and Markov logics, QBF, inconsistency
  measures, belief revision, the remaining action-language examples
  (monkey and bananas needs planning), ASP aggregates, arithmetic and
  optimisation: not expressible.

** Findings

1. *A solver timeout escapes the service.* =Service.label= raises
   =subprocess.TimeoutExpired= from adf-bdd instead of an =AidaError=
   (af.out, CF2Example). The complete semantics of a 28-statement ADF
   with three models (=smp_fol.fspy=) takes 80 s in adf-bdd with any
   backend, while grounded and stable are instant; 16 of the 28
   statements are fixed by grounded. Evidence for
   [[id:aida-multi-extension-labelling-cost]].
2. *A prover timeout leaves the session out of step.* On =aspic_random_01.fspy=
   (79 rule instances), labelling and evaluating every argument in one
   session, alone on the machine: a type-check replay exceeds the 5 s
   per-command timeout (=ACDC_TIMEOUT=), and from then on calls that
   succeed in a fresh session fail - refusals naming variables of other
   replays ("k0_2 is neither in your hypothesis"), =AttributeError:
   'NoneType' object has no attribute 'strip'= when parsing a reply
   without a proof term. 33 of 237 calls fail. With =ACDC_TIMEOUT=300=
   235 pass (single calls take up to 58 s); one call still reports a
   timeout after 5.4 s, cause not found, and the next fails out of step.
   New task [[id:aida-prover-timeout-desync]].
3. *Two spellings of a negation, inside one argument.*
   =spelling_one_argument.fspy=: a declared (A -> false) -> C applied to
   an inline proof that spells ~A passes =check=, but =graph= is
   refused ("a is neither in your hypothesis nor in your conclusion");
   spelled one way it is a value. =spelling_two_arguments.fspy= is the
   smallest case across two arguments ("This is not trivial"). Evidence
   for [[id:aida-negation-spelling-in-unfolding]], which so far
   described the case across arguments only.
4. *The negation bridge, in an action theory.*
   =logic/turkey_action.fspy=: loaded at 1 strictly, nothing unloads the
   gun, yet "loaded at 2" is undecided: the persistence chain of
   "unloaded" runs through the node =~Loaded_1[t]=, which no derivation
   of =Loaded_1= contests, so it stays IN beside =Loaded_1[t]= IN.
   Evidence for [[id:aida-strict-layer]]; bipolar deductive support,
   DeLP's =counterarg= and ABA's example4 show the missing transposition
   of the same task.
5. *Bare versus derived defeasible premises.* A defeasible premise ~X
   written as a counterargument that derives ~X from a presumption
   defeats the bare presumption of X outright (the asymmetric guard).
   The translator now writes it as a bare presumption of the refutation,
   which makes the two symmetric and AIDA warn about opposing
   presumptions. A negative premise in a rule body is owed as the
   refutation of X, so that counterarguments meet it - an obligation on
   =~X[t]= would only be met by an argument for ~X, which nothing
   contests. Both are encoding decisions the author may want to fix in
   the documentation of how to write a rule with a negative premise.
6. *Document view and issue view.* On the strict DeLP and action cases
   the document graph leaves undecided what the issue graph decides by
   strictness (=min_strict=, birds, turkey). Evidence for
   [[id:aida-issue-relative-strict-labels]].
7. *Elim names.* =elim a.= names the new hypothesis =a= when the goal is
   written =A -> false=, but =H2= when it is written =~A= - the name
   given is ignored.

Bugs found in Tweety on the way, for the record: =SimpleClStableReasoner=
never returns a claim set (=getModels= adds to the wrong set); the
rule preference of the first-order ASPIC+ example has no effect (any
order gives the same attacks); =DelpReasoner= answers UNDECIDED for
literals that have no argument at all, where DeLP's answer is UNKNOWN.
